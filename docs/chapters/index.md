# Course

Each chapter introduces a musical or perceptual concept and computes it in four ways:

1. from scratch with NumPy, so the maths is visible;
2. with py-mir-toolbox, which reproduces MIRtoolbox;
3. with librosa; and
4. with Essentia.

The chapter ends by explaining where the numbers differ and why.
